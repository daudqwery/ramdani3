# Ramdani Barkah - Oleh-Oleh Haji & Umroh

Website toko oleh-oleh haji dan umroh terlengkap dengan admin panel profesional.

## 🚀 Fitur Utama

### Toko Online
- Katalog produk lengkap (Kurma, Air Zamzam, Sajadah, Coklat Arab, dll)
- Keranjang belanja
- Checkout dengan multi-payment
- Tracking pesanan
- Halaman tentang kami & kontak

### Admin Panel (`/admin`)
- **Dashboard** - Statistik lengkap toko
- **Product Management** - CRUD produk dengan variasi & spesifikasi
- **Category Manager** - Parent & sub-kategori
- **Customer Manager** - Kelola data pelanggan
- **Payment Gateway** - Integrasi AyoLinx, OneBric, Duitku, Faspay, Midtrans, Xendit, TriPay, dll
- **Invoice Manager** - Buat, edit, kirim invoice via WhatsApp & Email

## 🛠️ Teknologi
- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- localStorage (Database)

## 📦 Instalasi

```bash
npm install
npm run dev
```

## 🌐 Deploy ke Hostinger

1. Build project: `npm run build`
2. Upload folder `dist/` ke hosting Hostinger
3. Selesai!
